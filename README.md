# terraform-aws-eventbus

Creates an Amazon EventBridge custom event bus, with optional KMS encryption, partner event source matching, and a resource policy.

Part of the [Raring Group](https://github.com/raringgroup) Terraform module library.

## Usage

```hcl
module "eventbus" {
  source = "git::https://github.com/raringgroup/terraform-aws-eventbus.git?ref=v0.1.0"

  context = module.context.self

  eventbus_name = "domain"

  # optional
  # kms_key_identifier = "<kms key arn, id, alias, or alias arn>"
  # policy_document    = data.aws_iam_policy_document.eventbus_policy.json
}
```

Naming and tagging come from [`terraform-null-context`](https://github.com/raringgroup/terraform-null-context). Add `_context.tf` to the calling configuration and pass `context = module.context.self`.

See [`examples/`](examples/) for complete, runnable configurations.

|------|-------------|------|---------|:--------:|
| eventbus\_name | (Required) The name of the new event bus. The names of custom event buses can't contain the / character. To create a partner event bus, ensure the name matches the event\_source\_name. | `string` | n/a | yes |
